# Order prepayment — November 9, 2026

Edit order now offers Request prepayment. Pickup orders can reserve an available room and vault before completion. The customer message includes the amount due, item count, chosen room, payment dedi, payment PIN, and travel directions. The payment PIN must differ from the pickup vault PIN.

Delivery customers receive a request for server, map, coordinates, spawn point, optional teleporter, and tribe name so the seller can collect payment. The message preview uses the saved order’s amount and count, and Save and copy saves the edit before copying the message.

The owner records receipt through Payment received and controls order progress. Pickup prepayment reservations stay with the order through pickup. Both templates thank the customer for prepaying.
