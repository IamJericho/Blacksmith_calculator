# November 11, 2026

Individual packing checklists on the order and courier pages show items still to pack first. Fully packed items remain available below them and return to the first group when unchecked.

On Processing, each order’s crafting checklist places fully crafted items after items still needed. Unchecking an item brings it back up.

The Processing checklist leaves the checkbox empty for partially crafted items. The crafted count and the quantity still needed show partial progress.

## Tek Revenue

Analytics now totals paid Tek orders from Orders and History. Date filters use payment dates where available and fall back to completion or original imported order dates. Undated paid Tek orders are included in All time.

Tek Revenue uses the same period buttons and date navigation as Item Analytics.
