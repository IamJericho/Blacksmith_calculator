# November 24, 2026

Outside-order pickup PINs now save in the existing private, cloud-synced internal settings instead of a page-session-only map. Refreshing retains the generated or edited PIN. Clearing an occupied location clears its saved PIN for the next customer. Storage failures are reported and do not silently present an unsaved generated PIN. Existing card layout and Edit dialog remain unchanged. PINs from a prior page session that were never saved cannot be recovered by this change.

Validation: fake-data checks cover refresh retention, edited PINs, clearing/reuse, preservation of unrelated settings and storage failure. Existing labeled controls, focus behavior and status/error announcements are retained; full assistive-technology conformance was not audited.

Room C now has two dedicated outside-order locations: C11 and C12. Both appear directly in Outside Orders with saved editable PINs and pickup instructions. Removed the old outside-occupancy checklist. C locations stay separate from regular-order, automatic allocation and prepayment location options; regular availability counts exclude them. Old A/B outside reservations are released, without changing any regular order’s saved room or PIN. Old PIN records are retained privately.
