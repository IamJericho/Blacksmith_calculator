# November 13, 2026

The Blueprint Library now lets signed-in users edit blueprint stats, notes, and recipe materials from a dialog. Edits use the existing workspace data storage and sync. Library edits apply to blueprint records and material copy text.

The editor shows materials on the current recipe. Use Add material to include another. Recipe-priced items show a price preview and an editable surcharge. Enter zero to remove a surcharge. Fixed-price items keep their catalog pricing rules.
