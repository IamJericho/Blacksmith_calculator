# November 17, 2026

Outside-order pickup locations now generate a four-digit vault PIN when their instructions are first opened. The PIN remains editable and is retained while filtering or rerendering during the current page session. Clearing the occupied location clears its draft PIN. Copy pickup instructions includes the displayed valid PIN. This does not set the vault PIN in game.

Validation: checked automatic generation, draft retention, location clearing and copy-preview source paths; retained native input label, keyboard operation and shared focus/theme styling. No new visual controls. Full assistive-technology conformance was not audited.

Outside-order cards display the PIN as text. An Edit button opens a matching modal with Save changes, Cancel and close controls; Escape closes the modal and focus returns to Edit. Changes reach copied instructions only after saving.

Room, vault and PIN now share one summary line, matching the other order cards. Saving a PIN updates that same line. Narrow screens may wrap the text naturally.

Outside-order Edit and Copy pickup instructions buttons share the existing wrapping action row below the message preview. Their visual and keyboard order match.
